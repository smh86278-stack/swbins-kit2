# 글 도우미 (PostKit)

사진 몇 장과 짧은 메모를 넣으면 **네이버 블로그 · 네이버 카페 · 인스타그램 · 틱톡**에 맞는 글을 **내 말투로** 써 주고, 말로 다듬어 주는 윈도우 앱입니다. 올리기는 직접 합니다.

## 준비

1. [Claude Code](https://claude.com/claude-code) 를 설치하고 터미널에서 `claude` 를 한 번 실행해 로그인합니다.
2. `PostKit.exe` 를 더블클릭합니다. 앱 창이 뜹니다(Edge). 창을 닫으면 잠시 뒤 스스로 끝납니다.

## 쓰는 법

1. **✍ 쓰기** — 메모를 적고(직접 겪은 사실일수록 좋습니다: 가격·시간·아쉬운 점·작은 디테일), 사진을 끌어다 놓고, 올릴 곳을 고른 뒤 「글 만들기」.
2. 플랫폼마다 카드가 나옵니다. 직접 고쳐도 되고, 「짧게」「캐주얼하게」 같은 버튼이나 「다듬기」 칸에 원하는 걸 적으면 그 부분만 고칩니다.
3. `[확인: …]` 자리는 AI 가 모르는 정보입니다(지어내지 않게 해 두었습니다). 직접 채우세요.
4. 「복사」 → 「글쓰기 창 열기」(평소 브라우저) → 붙여 넣고 사진을 올린 뒤 직접 발행.
5. **🗣 내 말투** — 예전에 직접 쓴 글을 몇 편 넣어 두면 그 말투로 씁니다. 네이버 카페 글쓰기 주소도 여기서 넣습니다.
6. **📂 지난 글** — 만든 글을 다시 열어 이어서 다듬습니다.

메모에 `#협찬` 이나 `#광고` 를 넣으면 글 첫 줄에 협찬 표기 문장이 들어갑니다.

## 왜 자동 발행이 없나

네이버는 자동화 프로그램으로 글을 올리는 것을 약관으로 막고, 걸리면 저품질 처리나 계정 정지가 됩니다. 그래서 이 앱은 **글 만들기까지만** 하고 올리기는 사람이 합니다. 인스타그램·틱톡 공식 API 업로드는 `DESIGN.md` §9 에 설계만 있습니다.

## 데이터

`%APPDATA%\PostKit` — `config.json`(말투 메모·기본 플랫폼·카페 주소) · `voice\`(내 글) · `posts\<날짜-메모>\`(메모·사진·플랫폼별 글·다듬은 이력).
기록은 `%LOCALAPPDATA%\PostKit\app.log`.

## 개발

```
python app.py                    창 띄우기 (--no-window 면 주소만 찍음, POSTKIT_DATA=<폴더> 로 시험 데이터 분리)
python -m unittest discover tests
python build.py                  dist\PostKit.exe
```

플랫폼 추가는 `platforms.json` 에 한 줄 + `prompts\<이름>.md` 한 장이면 됩니다(코드 수정 없음).
