  4. 네이버 카페에 올린다면 🗣️ 내 말투 → 설정에 카페 글쓰기 주소를 넣어요.

✍️글 쓰는 순서

  1. 메모 — 직접 겪은 사실을 짧게. 문장이 아니어도 돼요.
  2. 어디에 올릴지 고르기 — 여러 개 골라도 한 번에 써요.
  3. 사진 넣기 — 끌어다 놓거나 Ctrl+V. AI 가 사진을 직접 보고 글에 반영해요.
  4. ✨ 글 만들기 — 30초~1분. 나중에 다른 플랫폼이 더 필요하면 체크하고 ＋ 새로 고른 곳만 만들기.
  5. 다듬기 — 「짧게」「캐주얼하게」 버튼이나 말로 부탁해요. 직접 고쳐도 자동 저장돼요.
  6. 📋 복사 → ✏️ 글쓰기 창 열기 → 붙여 넣고 사진 올리고 발행은 직접.

🙋자주 묻는 질문

왜 자동으로 올려 주지 않나요?

네이버는 자동 프로그램으로 글을 올리는 걸 약관으로 막고 있어서, 걸리면 저품질 처리나 계정 정지가 될 수 있어요. 그래서 글 만들기까지만 하고 올리기는 직접 해요.

협찬·광고 글은요?

메모에 #협찬 이나 #광고 를 넣으면 첫 줄에 표기 문장이 들어가요. 협찬 글에 표기를 빼면 표시광고법 위반이 될 수 있어요.

글이 안 나오고 오류가 떠요.

왼쪽 아래가 빨간 점이면 claude 를 못 찾은 거예요. 설치 후 터미널에서 claude 를 실행해 로그인이 되어 있는지 확인하고 앱을 다시 켜 주세요. 사용량 한도에 걸렸을 때도 오류가 나요 — 잠시 뒤 다시 해 보세요.

만든 글과 사진은 어디에 저장되나요?

이 PC 의 %APPDATA%\PostKit 에만 있어요. 🗣️ 내 말투 → 📁 데이터 폴더 열기로 볼 수 있어요. 📂 지난 글에서 다시 열어 이어서 다듬을 수 있어요.

앱은 어떻게 끄나요?

창을 닫으면 1분 안에 저절로 꺼져요. 글을 만드는 중이면 끝난 뒤에 꺼져요.
